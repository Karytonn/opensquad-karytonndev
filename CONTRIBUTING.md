# Manutenção do fork pessoal

Este repositório é mantido para uso de Karytonn. A branch de trabalho e distribuição é `main`.

## Alterações

- Trabalhe somente neste fork.
- Preserve compatibilidade com squads existentes e faça backup antes de migrar dados.
- Atualize os templates e a documentação quando mudar a instalação ou o comportamento dos agentes.
- Preserve os créditos de autoria e os metadados de origem existentes.
- Nunca inclua credenciais, sessões de navegador ou dados pessoais em commits.

## Verificação

Execute os testes e o lint indicados em [FORK.md](FORK.md). A CI verifica o pacote e o dashboard no Windows e Ubuntu, incluindo os testes Python.

As instruções de instalação e atualização estão no [README.md](README.md).
